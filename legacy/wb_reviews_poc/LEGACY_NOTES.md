# wb_reviews_poc — жалобы на негативные отзывы WB (копия для переноса)

Скопировано 2026-09-25 с сервера для встраивания в новый автоответчик на отзывы.
Оригинал продолжает работать: `/root/claude-bot/ws/-1003890737169/wb_reviews_poc/`,
таймер `wb-reviews-cycle` (09:00, 15:00, 19:00 МСК), панель https://reviews.wild-expert.ru.

## ⚠️ Прежде чем запускать что-либо из этой копии

Оригинал **сам подаёт жалобы** во все три кабинета. Жалоба на отзыв одноразовая и
необратимая. Не запускайте `autosubmit.py` из копии против тех же кабинетов, пока
работает старый цикл, — получите двойные подачи и сожжёте единственную попытку.

## Чего в копии нет (намеренно)

- **Секретов:** `.env` (токены API отзывов трёх кабинетов, ключ DeepSeek), `panel.env`
  (логин панели), `data/cabinet_session.json` (живая сессия кабинета WB).
- **Данных:** база `data/reviews.db`, выгрузки API (`raw/`, `normalized/`), наборы и
  результаты прогонов моделей (`bench_*.json`), логи.
- Вместо базы — **`schema.sql`**: структура 5 таблиц (`reviews`, `complaints`,
  `ai_results`, `sku_stats`, `meta`) с индексами. Пустая база: `sqlite3 data/reviews.db < schema.sql`.

`report/field_coverage.md` оставлен: это сводка заполненности полей API отзывов, тексты скрыты.

## Конвейер

`WB_ACCOUNT=<ms|cr|hb>` → `collector.py` (отзывы 1–3★ из API) → `analyzer.py`
(LLM ищет формальное основание жалобы) → `autosubmit.py` (подача через кабинет).
Остальное: `panel.py` (Flask-панель), `cabinet.py` (сессия кабинета и подача),
`store.py` (SQLite), `accounts.py` (реестр трёх юрлиц), `watchdog.py`, `daily_report.py`.

## Что понадобится подставить своё

- **Токены API отзывов** — по одному на кабинет: `WB_FEEDBACKS_TOKEN_MS/_CR/_HB`
  (см. `.env.example`). Права токена: «Вопросы и отзывы».
- **Сессия кабинета** — в API WB подачи жалоб НЕТ, только через кабинет. Сессия
  вводится в панели вставкой запроса «Copy as cURL» из браузера (`cabinet.parse_curl`).
  Одна сессия открывает все кабинеты; переключение — кукой **`x-supplier-id-external`**
  (если менять только `x-supplier-id`, WB молча отдаёт прежний кабинет).
- **Ключи LLM** — код читает их из файлов, недоступных вне root:
  - `analyzer.py`: основная модель — `claude` CLI (`MODEL = "sonnet"`); запасные GLM
    (ключ из `/root/.openclaw/openclaw.json`), DeepSeek и Алиса (ключи из `/root/.env.shared`);
  - `watchdog.py`: токен Telegram-бота из `/root/claude-bot/.env`;
  - `bench_*.py`: те же файлы.
  При переносе эти пути надо заменить на свой источник ключей.

## Проверенные факты по WB (из работы оригинала)

- Отзыв допускает **одну** жалобу; текст ≤1000 символов, срок подачи 30 дней.
- Исход жалобы по API не виден — только `isAbleSupplierFeedbackValuation=false` и
  `supplierFeedbackValuation=<ключ причины>`; ключ **11 = «Отзыв не относится к товару»**.
- Статистика на 18.09: одобряется ~42,6% жалоб, WB решает в среднем за ~7 часов.
  Пустые отзывы и отзывы с тегом «плохое качество» одобряют заметно хуже.
